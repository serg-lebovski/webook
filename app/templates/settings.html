Расширение для браузера

Плагин для Chrome, Yandex Browser и Firefox. Позволяет сохранять ссылки на статьи прямо из браузера, не открывая WeBook.

  1. Скачайте ZIP-архив ниже
  2. Распакуйте в любую папку
  3. Chrome / Яндекс: откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное»
  4. Firefox: откройте about:debugging → «Этот Firefox» → «Загрузить временное дополнение» → выберите manifest.json
  5. При первом открытии плагина введите адрес сервера, логин и пароль

Приложение для Android

Мобильное приложение с озвучкой книг и статей голосовым движком Android (Text-to-Speech): фоновое воспроизведение, регулировка скорости и выбор голоса, автолистание абзацев.

  1. Скачайте файл webook.apk на телефон
  2. Откройте его и разрешите установку из этого источника
  3. При первом запуске сначала укажите адрес сервера, затем логин и пароль

Резервная копия

Скачать ZIP-архив со всеми вашими файлами. Имена файлов формируются из базы (автор — название). Архив содержит:

  • books/ — ваши книги (EPUB, FB2, PDF)
  • audiobooks/ — аудиокниги (по папке на книгу, главы по порядку)
  • covers/ — обложки книг
  • shared_books/ — книги, которыми с вами поделились
  • articles/ — сохранённые статьи в формате HTML
Большой архив может готовиться несколько секунд — дождитесь начала загрузки.
Восстановление из архива

Загрузите архив, скачанный из WeBook (содержит manifest.json). Восстановятся книги, аудиокниги, статьи, цитаты, а также полки, авторы и циклы. Точные дубли пропускаются — можно безопасно загружать в существующую библиотеку.
