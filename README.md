# WeBook

Персональная библиотека книг и статей с поддержкой OPDS, шарингом и встроенным ридером.

## Возможности

- **Книги** — epub, fb2, pdf; полки → авторы → циклы; автоматические метаданные и обложки; OPDS-каталог
- **Встроенный ридер** — чтение EPUB (epub.js), PDF и FB2 прямо в браузере; синхронизация позиции между сессиями
- **Статьи** — сохранение ссылок (аналог Pocket), папки, встроенный ридер с TTS (Web Speech API), видео YouTube/Vimeo
- **Аудиокниги** — загрузка нескольких файлов-глав, плеер с автопереходом, скоростью воспроизведения, таймером сна и сохранением позиции прослушивания; метаданные/обложка из тегов (mutagen)
- **Шаринг** — публичные ссылки (7 дней) на книгу или статью; шаринг с конкретным пользователем по логину; единая страница «Общий доступ» с вкладками «Поделились со мной» и «Поделился я»
- **Тёмная тема** — переключатель в шапке, выбор запоминается в браузере
- **Поиск** — полнотекстовый поиск по книгам (название, автор, описание, цикл, теги) и статьям (заголовок, описание, URL, теги, **полный текст статьи**); пагинация списков
- **Оценки и избранное** — звёзды 1–5 и избранное для книг, сортировка по оценке и фильтр избранного
- **Время чтения** — оценка времени чтения статьи и прогресс прокрутки (с восстановлением позиции)
- **Теги** — произвольные теги для книг и статей, фильтрация по тегу; страница управления (переименование/объединение/удаление)
- **Напоминания** — виджет на дашборде о шарах, истекающих в ближайшие дни
- **Дашборд** — статистика прочитанного, график активности чтения за 12 месяцев
- **Резервная копия** — выгрузка ZIP со всеми книгами и статьями из настроек
- **Массовые действия** — выделение книг/статей и групповые операции (прочитано, перемещение, теги, удаление)
- **Цитаты и заметки** — выделение текста в ридере (статьи, EPUB, FB2) → страница «Мои цитаты»
- **RSS-подписки** — авто-импорт новых записей лент в статьи (обновление по расписанию)
- **Браузерное расширение** — плагин Chrome/Yandex/Firefox для сохранения ссылок
- **Мультипользовательский** — у каждого своя изолированная библиотека; панель администратора
- **Безопасность** — защита от брутфорса (бан IP после 5 неудачных попыток); HTTPS настраивается на внешнем reverse-proxy
- **Логирование** — отдельные журналы (`auth`, `actions`, `errors`, `db`, `access`) в `logs/` с ротацией; просмотр в админ-панели

## Быстрый старт (Docker)

### 1. Клонировать и настроить

```bash
git clone https://github.com/serg-lebovski/webook.git
cd webook
cp .env.example .env
```

Откройте `.env` и обязательно смените `SECRET_KEY` и `DB_PASSWORD` на свои значения.

### 2. Запустить

```bash
docker compose up --build -d
```

Папки `books/`, `files/`, `links/`, `db/` создадутся автоматически рядом с `docker-compose.yml`.

### 3. Открыть

```
http://localhost:8000
```

Для HTTPS/домена поставьте перед приложением reverse-proxy (Nginx Proxy
Manager, Traefik, свой Nginx/Caddy) и проксируйте на `APP_PORT` (по умолчанию
`8000`) по HTTP.

При первом входе создайте аккаунт — он автоматически получит права администратора.

> **Администратор.** По умолчанию первый зарегистрировавшийся пользователь
> становится администратором (регистрация для остальных закрыта, пока админ её
> не включит). Либо задайте `ADMIN_USERNAME` и `ADMIN_PASSWORD` в `.env` — тогда
> при первом запуске администратор создаётся автоматически с этими данными.

## HTTPS

Приложение отдаёт только прямой HTTP на `APP_PORT` (по умолчанию `8000`) —
собственного reverse-proxy/TLS в комплекте нет. Поставьте перед ним что-то из:

- **Nginx Proxy Manager** / **Traefik** — если у вас уже есть один из них для
  других сервисов, добавьте proxy host на `<хост>:8000` (схема `http`), они
  сами получат сертификат Let's Encrypt.
- **Caddy** отдельным контейнером — если предпочитаете декларативный конфиг,
  `reverse_proxy app:8000` в Caddyfile даст то же самое.

`client_ip()` (`app/services/security_service.py`) читает `X-Forwarded-For` —
любой из вышеперечисленных proxy выставляет этот заголовок по умолчанию.

## Структура данных на сервере

```
webook/
├── docker-compose.yml
├── .env
├── books/      # файлы книг (epub, fb2, pdf)
├── files/      # обложки и изображения
├── links/      # тексты сохранённых статей ({id}.txt)
└── db/         # данные PostgreSQL
```

Все папки монтируются в контейнер — данные сохраняются при пересборке образа.

## Переменные окружения (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `SECRET_KEY` | Ключ для JWT (**обязательно сменить**) | `change-me-in-production-please` |
| `DATABASE_URL` | PostgreSQL URL | `postgresql://webook:webook@db:5432/webook` |
| `DB_PASSWORD` | Пароль PostgreSQL | `webook` |
| `APP_TITLE` | Название в интерфейсе | `WeBook` |
| `APP_PORT` | Внешний HTTP-порт приложения | `8000` |
| `ADMIN_USERNAME` | Логин админа при первой установке (опц.) | — |
| `ADMIN_PASSWORD` | Пароль админа при первой установке (опц.) | — |

## RSS-подписки

Добавляйте RSS/Atom-ленты на странице `/feeds` (кнопка RSS в разделе «Статьи»).
Новые записи автоматически сохраняются как статьи. Обновление по расписанию:

```bash
# вручную
docker exec webook python -m app.scripts.refresh_feeds

# ежечасно через cron
( crontab -l 2>/dev/null; echo "0 * * * * docker exec webook python -m app.scripts.refresh_feeds >> /opt/webook/logs/feeds_cron.log 2>&1" ) | crontab -
```

## Логи

Структурированные логи пишутся в `logs/` (отдельный том) с ротацией (5 МБ × 5):

| Файл | Содержимое |
|---|---|
| `auth.log` | вход/выход, регистрация, API-токены, баны/разбаны IP |
| `actions.log` | мутации (POST/DELETE): кто что менял |
| `errors.log` | необработанные исключения сервера |
| `db.log` | ошибки базы данных |
| `access.log` | HTTP-доступ с таймингом, IP и пользователем |

Просмотр без SSH — в админ-панели: **Администрирование → Логи сервера**
(`/admin/logs`). Уровень — `LOG_LEVEL` (по умолчанию `INFO`).

## Резервная копия БД

`scripts/pg_backup.sh` делает `pg_dump` из контейнера `webook-db`, сжимает в
`/opt/webook/backups/webook_<дата>.sql.gz` и хранит последние 14 копий.

```bash
# запуск вручную
/opt/webook/scripts/pg_backup.sh

# ежедневный бэкап через cron (03:30)
( crontab -l 2>/dev/null; echo "30 3 * * * /opt/webook/scripts/pg_backup.sh >> /opt/webook/backups/backup.log 2>&1" ) | crontab -

# восстановление
gunzip -c /opt/webook/backups/webook_<дата>.sql.gz | docker exec -i webook-db psql -U webook webook
```

> Экспорт книг и статей пользователя (ZIP) — отдельная функция в настройках
> (`/settings/backup`). `pg_backup.sh` сохраняет именно базу данных.

## Стек

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2, Jinja2
- **База данных:** PostgreSQL (prod) / SQLite (dev)
- **Парсинг книг:** ebooklib (EPUB), lxml (FB2), pypdf (PDF)
- **Парсинг статей:** trafilatura
- **Ридер:** epub.js (EPUB), браузерный PDF viewer, собственный FB2→HTML конвертер
